# Tweet me — تطبيق أندرويد أصلي (Kotlin)

مراسلة بأسلوب واتساب: حسابات، محادثات فردية، نصوص، صور، رسائل صوتية، علامات القراءة،
ثيم أزرق وأسود يتحكم به المستخدم (وضع الشاشة، لون التطبيق، خلفية المحادثة، لون الفقاعات، حجم الخط).
بلا ملفات ويب: واجهات Jetpack Compose أصلية، وخدمة Firebase المجانية.

## بنية المشروع (أين أعدّل؟)

| المجلد | ما فيه | متى تفتحه |
|---|---|---|
| `core/` | النماذج (`Models.kt`) وأنواع الأخطاء (`AppError.kt`) | إضافة حقل أو نوع رسالة |
| `data/ChatBackend.kt` | **العقد** بين الواجهة والخدمة | أي خدمة جديدة تبدأ هنا |
| `data/FirebaseBackend.kt` | التنفيذ الحقيقي على Firebase | تغيير هيكل البيانات |
| `data/DemoBackend.kt` | الوضع التجريبي بلا إنترنت | اختبار بلا سحابة |
| `data/PrefsStore.kt` | إعدادات المظهر المحفوظة | إضافة خيار جديد |
| `media/` | ضغط الصور والتسجيل والتشغيل الصوتي | تغيير جودة الوسائط |
| `ui/theme/` | الألوان والثيم وقائمة خلفيات المحادثة | إضافة لون أو خلفية |
| `ui/auth` `ui/chats` `ui/chat` `ui/settings` | الشاشات | تعديل الواجهة |
| `ui/AppNav.kt` | التنقل والتبويبات | إضافة شاشة |
| `res/values/strings.xml` | **كل النصوص العربية** | تغيير أي كلمة |
| `gradle/libs.versions.toml` | إصدارات المكتبات | الترقية |

### قواعد التعديل
- شاشة جديدة: ملف في `ui/<اسمها>/` + سطر `composable(...)` في `AppNav.kt` + نصوصها في `strings.xml`.
- خدمة جديدة (مجموعات، حالات، مكالمات): أضف دوالها في `ChatBackend`، ونفّذها في `FirebaseBackend` و`DemoBackend`، ثم استدعها من `ViewModel`.
- خيار إعدادات جديد: حقل في `AppPrefs` + مفتاح ودالة حفظ في `PrefsStore` + عنصر في `SettingsScreen`.
- لا تضع منطقاً في الشاشات؛ المنطق في `ViewModel` والخدمات.

## البناء (من الهاتف، مجاناً)
البناء يتم على GitHub Actions عبر الملف `.github/workflows/build.yml`:
كل تعديل تحفظه في المستودع يبني APK جديداً ويضعه في صفحة **Releases** باسم `TweetMe.apk`.

## ربط Firebase
1. ضع `google-services.json` في المجلد `app/` (اسم الحزمة: `com.tweetme.app`).
2. فعّل Authentication (Email/Password) وFirestore، وانسخ `firestore.rules` إلى تبويب Rules ثم Publish.
3. احفظ التعديل في GitHub فيُبنى APK جديد متصل بالسحابة تلقائياً.

بدون الملف يعمل التطبيق بوضع تجريبي محلي (محادثة مع «Tweet بوت»).
